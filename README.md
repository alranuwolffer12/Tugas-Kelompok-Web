Code Quest
Aplikasi web mini-game edukasi interaktif untuk membantu pemula mempelajari dasar-dasar pemrograman dengan cara yang menyenangkan.

Fitur Utama
Kategori Pembelajaran: Kuis interaktif untuk Python, HTML, CSS, dan JavaScript.

Fitur Tambahan: Mode Easter Egg (Meme Indo) untuk variasi kuis yang kasual.

Sistem Penilaian: Evaluasi jawaban secara instan lengkap dengan progress bar dan statistik skor akhir.

Teknologi
HTML5, CSS3, & JavaScript (Vanilla JS)

Font Awesome (Ikon antarmuka)
